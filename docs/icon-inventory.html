What the audit found

Read before redrawing anything: three of these are wiring, not artwork, and a new set inherits them unless they are fixed at the same time.

  1. Twenty-two flyout rows draw the Line icon

    The Work Axis, Work Point and Direct Edit flyouts carry string keys — waAuto, wptAuto, deMove — that exist in no icon map. ribbon.dart:2695 resolves IC[key] ?? PL[key] ?? IC['line34'], so every row in those three menus shows a diagonal line with two grips. m115_ribbon_icons_test only checks MAP['key'] lookups, so it cannot see these.

  2. Thirty-three icons are drawn and never shown

    The AX (8) and PN (9) maps were drawn for exactly the two flyouts above and are never read. PD (12) belonged to the old 2D Pattern and Chamfer dialogs, which no longer import the icon set at all. Four Place Constraint helpers round it out. Every one of them is in this sheet, marked unused.

  3. One icon has no colour at all

    IN['constr'] writes stroke="\$GC". The dollar is escaped, so the literal text $GC reaches the SVG and the Construction line renders with no stroke — the glyph is two blue dots with nothing between them.

  4. Five icons are set in fonts an iPad does not have

    The letter A in Text, Geometry Text and Import ACAD is font-family="Segoe UI"; the fx in Equation Curve is Georgia. Neither ships on iOS, so the glyph falls back to whatever the platform substitutes and the weights stop matching the rest of the set.

  5. The set is five grids and twenty-three stroke weights

    ViewBoxes of 34, 26, 24, 18 and 16 px sit next to each other inside single panels, and stroke widths run from 0.5 to 6. Half of the geometry also lands on half-pixel coordinates, because the grip helper subtracts size / 2 from an integer centre. At 18 px a 0.5 stroke is under a third of a device pixel.

  6. The recolour flattens 53 hues into four

    themedIcon() sorts every colour by hue into accent / good / annotation / error and rewrites its lightness. On the light palette every chromatic stop is compressed into L 0.16–0.46, so the three-tone shading that makes a cube read as a cube collapses into one value. Four icons written as #fff are skipped by the #rrggbb regex entirely and stay pure white on paper. Switch the render mode above the grids to see it.
