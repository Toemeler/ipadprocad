The rules

Four decisions do most of the work. They are what make eight separate drawings read as one panel, and they are the part worth agreeing on before the artwork.

One grid
24 × 24 for all eight, scaled to 34 or 18 by the ribbon. Today the panel mixes a 34 grid and an 18 grid, so the same line weight arrives at two different thicknesses.
One weight
1.5, round caps and joins, no fills. Today these eight use eight different stroke widths between 0.5 and 1.8, plus twelve filled shapes.
Accent = the operation
The arrow, the axis, the path, the helix, the raise. The eye lands on the one thing that separates Extrude from Sweep instead of on a blue cube that all of them share.
Three colours
Down from ten in this panel alone, and from four near-identical blues. All three survive themedIcon() — the greys ride the ink ramp, the blue lands on the accent. #C9CDD2#9AA0A6#3D9BE9

The code

Ready to drop into lib/svg_icons.dart — nothing else in the file changes, and every key keeps its name so no call site moves. Not applied yet.

// Create panel (3D part features) — M__ redraw.
//
// One 24-px grid for the whole panel, one stroke weight (1.5), three
// colours. ACCENT marks what the command DOES; the two neutrals are the
// geometry it does it to. Every colour survives themedIcon(): the greys
// are under 12% saturation so they ride the palette's ink ramp, and the
// blue sits at hue 207 so it lands on T.accent in both schemes.

const CS = '#9AA0A6'; // geometry, secondary
const CA = '#3D9BE9'; // the operation

    '\$inner</svg>';

What I need from you

  • Extrude and Revolve carry the panel — if those two are right the rest follow. Are they?
  • Coil is the one I am least sure of: four turns is readable but busy at 18 px. Three?
  • Derive is the only icon with a document in it. Right metaphor, or should it be two bodies?
  • Decal uses a literal picture mark. Too generic next to seven geometric icons?
  • Is the accent doing too little? I kept it to one element per icon on purpose — say if you want more colour.
