Ribbon icon redesign

The new ribbon icon system (design/icons/SPEC.md) shown in the faithful Carbon Pro Neutral app mock, in every ribbon, overflow menu and flyout, and in an old | new atlas. Every icon goes through a port of icon_theme.dart's _map. The default is the app default: left rail, names off, one column (28 pt glyphs in 36 pt cells). Keys not redrawn yet keep their current drawing and carry a ● mark.

The v2 reference icons

SPEC v2 “Modern Crisp”, drawn by tools/icon_redesign/families/ref.py through lib/crisp.py. Each strip is the one-column rail at real size (28 pt glyphs in 36 pt cells), then 18 pt (overflow menu), then ×4 for inspection, on both Carbon Pro Neutral rails through the selected _map.

App mock

Rail Auto is _RailFit: one column when the panels fit the window height, otherwise two. The part rail fits in one column; the sketch rail needs two. The mock grows taller rather than clipping a forced single column.

Ribbons, overflow menus and flyouts

A static transcription of ribbon.dart (reused from tools/ribbon_icon_mockup). In the new set the flyouts use their per-row icons: the Axis rows AX.*, the Point rows PN.* and the Direct rows DE.*, instead of the old Line-icon fallback. Parameters uses IN.params.
